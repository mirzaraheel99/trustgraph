# TrustGraph Go-to-Market and Pilot Plan

## 1. Document Purpose
Define the initial healthcare pilot and GTM learning plan.

## 2. Scope
Travel nurses, allied healthcare professionals, healthcare staffing agencies, selected hospitals/health systems.

## 3. Definitions
- Pilot: controlled real-world use with limited participants and support.
- Readiness: evidence-backed profile completeness for a target placement workflow.

## 4. Actors
Professional pilot users, staffing agency admins/recruiters, employer reviewers, TrustGraph operations, support.

## 5. Assumptions
Pilot emphasizes manual/assisted verification and workflow learning before broad automation.

## 6. Requirements
- Onboard professionals with Passport profiles.
- Onboard agencies/employers with Verify accounts.
- Track access requests, approvals, shared profile review, missing records, verification cases.
- Capture feedback and operational friction.
- Define pricing hypothesis.

## 7. Workflows
Recruit pilot -> onboard org -> invite professionals -> build Passport -> request/approve share -> review readiness -> resolve exceptions -> collect feedback.

## 8. Business Rules
Pilot must not imply official background-check compliance without legal-approved workflows.

## 9. Permissions
Pilot organizations see only approved shared records.

## 10. States
Recruiting, onboarding, active pilot, feedback, exit review, expansion.

## 11. Exceptions
Sensitive legal/compliance issues route to approved TrustGraph operator and counsel review where needed.

## 12. Security and Privacy
Use real-data safeguards, consent, and clear privacy notices before pilot.

## 13. Audit Requirements
Pilot workflows must generate Audit Events for trust-critical actions.

## 14. Dependencies
MVP, support process, legal review, privacy notice, security readiness.

## 15. Acceptance Criteria
Pilot proves professionals can create portable verified records and employers/agencies can review authorized evidence faster and more safely.

## 16. Open Decisions
Pilot partners, pricing, support SLA, success metric targets.

## 17. Out-of-Scope Items
Public launch campaign.

## 18. Change History
Initial bundled build-prep version.
